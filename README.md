# Raven Remodeling LLC — Single-Page Website

Clean, modern, single-page website for **Raven Remodeling LLC**, a family-owned remodeling and custom tile installation company serving **Newberg, Yamhill County, and the Greater Portland Metro Area since 2024**.

## Key Features & Improvements
- **Single-Page Architecture**: Streamlined navigation with smooth scrolling to **Services (Tile Work & Remodeling)**, **Completed Gallery**, **About Us**, **Greater Portland Service Areas**, and the **Bottom Contact Form**.
- **Removed Clutter**:
  - Removed the "Book Online" page and booking widgets.
  - Removed all supplier mentions and logos (Sherwin-Williams, CFM, Castico, Pallmann).
  - Filtered the photo gallery to showcase **only 100% completed work** (all work-in-progress, tools/ladders, unpainted drywall, and before/prep photos were removed).
- **Color Palette**:
  - **Sky Blue (Light)**: `#8ecae6`
  - **Blue Green**: `#219ebc`
  - **Deep Space Blue**: `#023047`
  - **Amber Flame**: `#ffb703`
  - **Tiger Orange**: `#fb8500`
- **Bold Typography**: High-impact `Montserrat` (700/800/900) headings paired with `Plus Jakarta Sans`.
- **Local SEO Optimized**:
  - Targeted metadata, semantic headings, image `alt` descriptions, and `HomeAndConstructionBusiness` JSON-LD structured data for **Custom Tile Work & Home Remodeling in the Greater Portland Area (Since 2024)**.

## Project Structure
- `index.html` — Single-page HTML5 site with SEO metadata & JSON-LD schema
- `styles.css` — Custom responsive styling using the 5-color palette
- `script.js` — Mobile menu, gallery filtering, lightbox modal, and contact form handler
- `assets/` — Official Raven Remodeling logos and optimized completed project photos
- `robots.txt` & `sitemap.xml` — Search engine indexing files
